# 三视图与贴图质量检查

读取时机：基础图或生成层准备好后，执行主技能步骤 2、3、5、6。以下是可用 Pillow / NumPy、图像编辑器或同等工具实现的检查约定；本技能不附带一键检测程序。先保留原始文件，再写工作副本、检查图和报告。数值只用于说明本次比较方法，不把来源项目的参数当成通用阈值。

## 1. 三视图一致性卡

对每个目标视图记录：输入文件及哈希、画布尺寸、角色面向与左右约定、头顶、眼 / 耳线、肩、腰、脚底、发饰 / 尾巴 / 翅膀和其他不对称服饰的可见特征。没有露出的标志填“不适用”或“推测”，不凭其他视图声称观测到了。

- 并排显示各视图，以相同显示缩放和背景核对身份、体量、服装、视角、头顶与脚底。侧面看是否真正侧身，背面检查是否误出现正面五官或装饰。
- 已有图就以现图为基准，只在确实缺少或错误严重时重新生成；脚底对齐不是要求所有角色姿态完全相同。允许有证据的整体平移 / 等比缩放并记录变换；内部比例不一致不能靠局部拉伸掩盖。
- 需要生成缺失视图时，可比较两种候选：一张身份主图配相同标志卡、分别生成目标视图；或同一宽画布保留主视图、其他栏生成侧 / 背。每个候选逐视图审核，不将某次成功经验当作模型普遍规律。
- 从设定图按栏导出时，先确认分栏范围、每栏确有前景并记录坐标。不要只保留最大连通域或把画外细节归零：漂浮饰物、尾巴、发丝可能独立且落在主体框外。检查每栏边缘有无截断，再做需要的整体放置；不得让相邻栏污染目标视图。

## 2. 单件完整性与真实透明度

1. 按视图清单逐件查看：语义正确，物件没有被误分成光影色块；自身轮廓完整，被遮挡处有合理延伸。头发检查脸后内层，衣身检查肩侧和手臂后面，腿检查髋部，手臂检查袖口、手和手指。真正不可见且无需交付的件写不适用，缺失或存疑标待处理。
2. 检查文件能否解码、颜色模式、尺寸及 alpha 分布，查看直方图和预期透明区的像素。RGB 图片、全不透明 alpha 或画出来的棋盘格不能因为扩展名是 PNG 就算透明；完全铺满画布的真实部件应结合图像语义判断，不能仅凭没有透明区自动认定失败。
3. 在深、浅和中性纯色底分别预览同一透明层的边缘；放大检查发丝、白衣、眼睛、描线、饰物与局部半透明。不要因为背景颜色相近就把白衣、亮色发丝或饰物当背景。
4. 如生成服务不支持可靠的透明输出，选与整个目标部件（包含小饰物）颜色分离的纯色背景，保存原始返回，再做色键去背。估计实际背景而非假定模型精确画出指定颜色；对边缘混色可尝试软 alpha 和前景 / 背景混色反解，比较前后，并记录色键、工具与参数。背景与前景接近、阴影 / 渐变 / 压缩严重时结果不可靠；更换背景、模型或手工修复，不能把去背成功当成自动验收。
5. 对小连通区域只做标记和位置报告；不能仅按面积或最大连通域删点。断开的睫毛、细发丝、小饰物可能是真实内容。需要清理时保留原稿、对比确认并记录具体修改。
6. 如局部高分辨率候选使用了裁块，检查其有效前景是否触碰裁块内部边缘；触边是**可能截断**的警告，原图外边缘另判。选择适合该素材的 alpha 阈值并记录：极细、低 alpha 的发丝可能被阈值漏掉，不触边也不能证明完整。

## 3. 放回画布与遮挡关系

- 对每件记录 `view`、`name`、图像尺寸、原画布尺寸、裁切框与 offset、缩放 / 平移 / pad、来源输入及哈希、模型 / 请求或工具版本、任务标识。标出原始、去背和编辑版本的关系；本参考描述报告内容，不要求伪装成某个现有工具的格式。
- 变换只按真实输入 / 返回 / 裁切记录计算。提供了局部裁块时，把该局部坐标映射回所属视图基础画布；图像等大不代表内容已经配准。变换不明或比例有漂移时标待处理，不能猜一个独立拉伸掩盖错位。
- 对已知变换的透明层使用预乘 alpha 缩放后解除预乘；核查深浅底边缘和裁切后 offset。只裁透明外边，不裁掉隐藏延伸。
- 无深度图时明确从后到前的顺序。每个视图都独立判断：例如手臂在肩处位于衣身后、手掌又跨到衣身前，需要重新定义前后层或标未解决；一个整体层的固定顺序不可能表达局部交叉。已有按层顺序生成前后件时，仍检查交界处和两片自身完整性。
- 有深度时记录来源与运行标识；仅在相同标尺可比且实际提供逐像素深度时做逐像素遮挡。不同运行的深度不能直接比较；也不根据普通 API 的输出想象出深度。

## 4. 重合成与缺口报告

1. 把所有层按 offset 放回同一视图画布，按已声明的顺序 / 可比深度合成。对照基础图分别保存：重合成图、颜色差异图和漏覆盖图；必要时附单件接触表与肩颈、手腕、发际线的局部放大图。
2. 先建立并目检**基础图人物前景 mask**：只有真实 alpha 能区分人物与背景时才由 alpha 阈值生成；RGB、全不透明图或透明通道不可靠时，使用经核验的去背结果或人工 mask，保留原图并记录 mask 来源、尺寸、阈值和处理。无法可靠区分前景背景时，`alpha_miss`、前景 IoU 与基于此 mask 的缺口定位记为无法计算，不可报告通过。
3. 有可靠前景 mask 后，选择并记录合成覆盖阈值 `composite_alpha_threshold`。定义 `base_fg` 为该 mask，`miss = base_fg AND composite_alpha <= composite_alpha_threshold`，`alpha_miss = count(miss) / count(base_fg)`。阈值、通道范围和分母必须写进报告；前景 mask 为空时记为无法计算，不把结果当 0 或通过。半透明细节需另行目检，阈值会改变漏检结果。
4. 对 `miss` 做连通区域标记，记录各区域面积、半开边界框 `[x0,y0,x1,y1)`、所属视图，以及附近部件的名称 / 距离或覆盖情况。可按面积排序以便排查，但保留小区域的记录，不能自动删除发丝、饰物或内部孔洞。附近部件只是修复候选；原因无法确定就写 `unknown`，不要把接近当成责任归因。
5. 在统一色彩处理和相同底色下比较基础图与重合成图；记录 RGB 平均绝对差（0–255）、前景 IoU 的统计区域、阈值及差异图。也检查合成图超出基础图的部分；只有颜色差异不能区分合法遮挡补全与错位。尺寸 / 坐标不一致先按记录变换处理，不能对未配准图片直接算成验收值。
6. 每个缺口列出修复建议，如“复查左肩 / 衣身两层”或“重做后发延伸”；修复后重新计算，保留之前的结果和实际改动。低误差、空漏覆盖图或绿色结构检查都不能证明被遮住的轮廓真实完整，仍需逐层和人工视觉检查。

报告建议包含：检查状态（通过 / 待处理 / 无法计算）、输入 / 各部件哈希、尺寸与变换、顺序 / 深度来源、阈值与统计区域、差异图和缺口图路径、区域列表、处理与未解决项。失败不能静默当成空列表或通过；临时结果和正式交付分开。

## 5. 仅保留周围的局部编辑：区域外检查

单件提取会移除其他部分，不能拿单件透明层与整人图做“编辑区外必须不变”比较。只有任务明确要求**在已有图上改一块并保留其他内容**时才使用以下检查：

1. 记录编辑前后文件、相同画布或已知真实变换，以及允许编辑的区域 / mask 和保护区；无法确定对应关系时报告无法比较。
2. 对齐到同一坐标和颜色处理后，统计保护区和编辑区外的变化比例、平均差和位置；阈值 / 可选抗噪处理、比较区域与变换一起记录，并输出差异图。检查语义变化和边缘细节时也看未模糊原图。
3. 区域外变化超出本次约定时重新生成或修正；阈值之下的变化、保护区未覆盖的地方及语义正确性仍需人工确认。结果只证明本次检查范围内的像素变化，不能证明透明层、补全内容或整套贴图已经合格。
