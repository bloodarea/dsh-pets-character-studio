    帮助与快捷键

    每个区域一句话

    左侧工具条分两组：操作 = Q 选择（只选中）· H 拖拽（视野开关）· V/G 移动 · R 旋转 · S 缩放 · W 指向；视图控制 = + 放大 · − 缩小 · F 适应窗口。分区名在展开态显示，收起态（44px）只留分隔线。当前工具是实心蓝底 + 左侧白条 + 加粗，其余灰色。拖拽是开关：点一下进、再点一下出（退出回到进入前的工具）。
    画布直接拖人物改姿势；滚轮缩放。拖视野有三种方式：① 点工具条的「拖拽」按钮（常驻，再点一次退出）② 按住 Space（临时，松手即回）③ 按住鼠标中键。左下角切换「绑定姿态 / 动画」。
    右栏 · 图层点一行选中部位；👁 显示/隐藏、🔒 锁定、搜索框过滤。「显示顺序 / 骨骼层级」切换排列方式。
    右栏 · 属性整块检查器（标题 + 选中部件 / 骨骼 / 附件 / 骨架结构）已移除，右栏现在只有部件列表。文档模式与 AutoKey 仍在顶部第 2 排；K 打关键帧、Shift+T 自由变换、[ ] 层级调整都还在。数值与层级/显示/锁定等操作走 __characterEditor 接口。
    底部时间轴一个播放头、一条轨道列表：双击行打键，拖菱形改时间，左上切 Graph。按 Tab 展开/收起。
    更多分区「骨架结构 / 调试」也已在 0.9.50 移除。右栏只剩部件列表与四个主分页（部件 / 台词 / 表情 / 动画）。骨架结构、镜像、轴心、调试诊断全部改为 __characterEditor 接口：skelCreate / mirror / pivot / diagnostics。

    快捷键速查

    Q选择工具（点选部位，不改数据）
    V / G移动工具（V 是 PS 习惯，G 是 Blender 别名）
    R / S / W旋转 / 缩放 / 指向
    H拖拽开关：按一下进入（画布左键拖动=移动视野，不碰部件），再按一下退出并回到进入前的工具
    Space按当前区域决定：指针在画布 / 图层区 = 按住临时拖拽；指针在时间轴 / 播放条 = 播放暂停。
    K打关键帧（时间轴展开时打到时间轴，否则记当前位置）
    Delete删除关键帧（会先弹页内确认）
    P播放 / 暂停
    F / Shift+F适应窗口 / 只看选中
    Tab展开 / 收起时间轴
    [ ]层级下移 / 上移
    ←→↑↓微调 1 单位（Shift ×10）
    + -放大 / 缩小
    Ctrl+Z撤销
    Ctrl+Shift+Z / Ctrl+Y重做
    Ctrl+S保存（有写回目标时弹保存菜单，否则下载副本）
    Esc取消当前拖动 / 清除选择 / 关闭浮层与菜单
    ?打开本帮助

    输入框、下拉框、菜单聚焦时不会触发上面的单键快捷键。鼠标在画布上时 Space 是拖拽，在时间轴上时 Space 是播放暂停——这是同一个键按区域分工，不是两个模式。

    快捷键（可自定义）

    绑定只保存在浏览器 localStorage（dsh.character-editor.preferences），不写入人物包；点「重绑定」后按新组合键，Esc 取消。

    保存与撤销

    撤销粒度一次拖动 / 一次方向键 / 一次层级调整 / 一次数值提交各记一条；没有实际改变不写撤销。
    拖动中按 Esc回滚到本次手势开始前。
    保存顶栏「保存 ▾」：下载副本（永远安全）或写回原包（需要本地服务）。写回成功后才清除「● 未保存」。
    切包保护有未保存改动时打开另一个人物包，会先弹四选一：保存到原包 / 下载副本后继续 / 放弃调整 / 取消。
    吸附默认关闭；打开后平移取整 1 单位、旋转 5°、缩放 0.05。开关在「视图」菜单或 __characterEditor.setSnap(true)。
    曲线段 Key时间轴上带琥珀描边的 Key 在贝塞尔曲线段内，只读；在 Graph 视图里可直接改曲线类型与手柄。
