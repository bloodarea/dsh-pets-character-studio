    已记录的问题

      只需四步

      1. 打开工程，点「添加问题」。
      2. 选有问题的部件，在图上圈出位置。
      3. 写一句哪里需要改。
      4. 点「保存标注」。

      矩形框选、多边形框选、魔棒或画笔都可标记问题。橡皮擦只擦标记。

      可连续圈多处。圈错了点「撤销」，圈好了点「完成圈选」。

      部件页：看层级与像素数，点眼睛只看或隐藏某件；勾工具栏「部件颜色」按部件上色（双/四视图里画在「部件叠加」那一格）；点一行即把它设为当前问题的问题部件（再点一次取消选中）。选中的部件会按自己的配色铺一层＋白边，不开部件颜色也能看到。

      视图：单视图只看当前图；双视图左原立绘、右部件叠加（两格都能直接圈选）；四视图是三张静态立绘（正面 / 侧面 / 背面）加一格部件叠加。点某张立绘即选中它（绿框，默认正面），部件叠加跟着显示该视图的拆件；该视图没有拆件时那一格显示空视图。载入工程后默认回到单视图。

      哪些东西只影响部件叠加：部件页的眼睛、部件颜色、完整部件底图，在双/四视图里只改变「部件叠加」那一格；三张立绘始终是原始静态图（单视图则整块画布一起变）。

      缩放拖动：四格共用一套缩放（坐标对齐）。只在「部件叠加」格里滚轮缩放、拖动平移（或空格/中键拖），三张立绘跟着一起动；双击任意一格一起适配。光标停在部件叠加上时，对应立绘同一位置会出现绿点。按住 Alt 出放大镜。

      完整部件：勾上后用层叠图当底图（默认开），取消则回到纯原立绘。
